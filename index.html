Endpoint de recebimento (para o seu sistema chamar)

Se preferir, configure o sistema interno para enviar os produtos diretamente para o MercadoAuto, chamando:

POST /api/integrations/erp/products

Envie um array de produtos (sku, title, description, price, quantity, brand, category) com o token da sua conta no cabeçalho Authorization. Os produtos chegam como rascunho e podem ser gerados com IA e publicados a partir da aba Anúncios.

Descrição modelo dos anúncios

Defina a estrutura que todo anúncio gerado com IA deve seguir (use colchetes para os campos que devem ser preenchidos, ex: [MARCA]). Quando a IA não encontrar um dado real, ela escreve "Não informado" em vez de inventar — nunca reescreve o restante do seu modelo. Se você não configurar nada aqui, o modelo padrão é usado.
